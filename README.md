# Clase GitHub

Repositorio de práctica del Módulo 5 de Programación Avanzada para Ciencia de Datos.

## Propósito

Observar de forma visual el recorrido de un cambio:

1. clonar un repositorio;
2. modificar un archivo;
3. revisar las diferencias;
4. crear un commit;
5. publicar una rama;
6. abrir y revisar un Pull Request en GitHub.

## Regla de seguridad

No incluir credenciales, tokens, datos personales ni archivos sensibles en el repositorio.
